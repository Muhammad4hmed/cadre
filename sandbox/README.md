# Sandbox

F5 opens the Extension Development Host on this folder, so the agent always has a
working directory and the chat is usable the moment the window appears.

Throwaway space — put files here to give the agent something to read and edit
without touching the extension's own source.

To dogfood the extension on its own repo instead, pick the
**Run AI Team Extension (dogfood on this repo)** configuration from the Run and
Debug dropdown. The agent can edit the extension's source in that mode.
